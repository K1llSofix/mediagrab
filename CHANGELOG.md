# Список изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии нумеруются по [SemVer](https://semver.org/lang/ru/).

## [1.1.1] — 2026-11-22

### Исправлено
- GIF больше не может удалить уже скачанный MP4: исходник для GIF качается под временным именем `*.gif-src.mp4`, и удаляется только он.
- Повторная загрузка того же видео с другим качеством заменяет старый файл, а не молча пропускает его с отметкой «готово». Докачка после сбоя сети работает как раньше.
- Фрагмент видео сохраняется с суффиксом вида `[clip 90-120]` и не перекрывает полный ролик с тем же названием.
- Системные уведомления об окончании очереди: теперь их показывает главный процесс, раньше окно блокировало разрешение.
- Загрузки и запросы информации ждут окончания обновления yt-dlp, раньше новая загрузка могла стартовать во время перезаписи программы.
- Субтитры с настройкой `ru, en` или `ru;en` больше не отключаются молча: значение приводится к `ru,en`.
- Большие каналы и плейлисты не падают по таймауту: список ограничен 200 видео.
- Добавление подписки во время проверки подписок больше не сбрасывает флаг занятости и не ставит одни и те же видео в очередь дважды.
- Смена прокси в настройках сразу действует и на загрузку картинок Pinterest, без перезапуска.
- Прокси `socks5h://` и `socks4a://` принимаются.
- Зарезервированные имена Windows (`CON`, `aux`, `nul` и другие) в названии файла получают префикс `_`.
- Ошибка HTTP 403 показывается с понятной подсказкой на пяти языках; правило для SSL больше не срабатывает на посторонних словах.
- Ссылки из вставленного текста очищаются от закрывающих `)` `,` `.`; `youtu.be/x`, `watch?v=x` и `/shorts/x` считаются одним видео, в том числе при отдельных вставках.
- Карточки с ошибкой получения информации не сохраняются в очереди между запусками.
- Плагин PO-токена на Windows больше не скачивается заново при каждом включении.

### Изменено
- Релиз в GitHub Actions останавливается, если тег не совпадает с версией в `package.json`.
- Документация: короткий `README.md`, подробное руководство в `docs/GUIDE.md`, добавлен файл `LICENSE` (MIT).
- Из публичной копии проекта удалены неиспользуемые файлы.

## [1.1.0]

### Добавлено
- Форматы WebM, GIF, M4A и FLAC, обложка и теги в аудио.
- SoundCloud и улучшенная поддержка VK Видео (понятные ошибки для закрытых видео).
- Подписки на каналы и плейлисты, трей, перетаскивание готовых файлов в другие программы.
- Выбор языка звука, субтитров и глав, точная вырезка фрагмента.
- Действие после очереди: закрыть программу, сон или выключение.
- Окно настроек с вкладками, интерфейс на пяти языках (русский, английский, украинский, немецкий, испанский).
- Автообновление приложения через GitHub Releases, журнал ошибок и сохранение отчёта.
- Шифрование сохранённого входа в YouTube средствами системы, проверка контрольных сумм yt-dlp и Deno.
