# MediaGrab

Простое настольное приложение для скачивания видео, аудио и картинок. Вставьте ссылку, выберите формат и качество, нажмите «Скачать».

**Сайты:** YouTube и Shorts, TikTok, Instagram, VK Видео, SoundCloud, Pinterest.
**Форматы:** MP4, WebM, GIF, MP3, M4A, FLAC.
**Платформы:** Windows (готовый установщик), macOS и Linux (сборка из исходников).
**Язык интерфейса:** русский, английский, украинский, немецкий, испанский. Есть светлая и тёмная темы.

## Скачать

Готовый установщик для Windows лежит в разделе [Releases](https://github.com/K1llSofix/mediagrab/releases/latest). Скачайте `MediaGrab-Setup-*.exe` и запустите.

Установщик пока не подписан сертификатом, поэтому Windows SmartScreen может показать предупреждение. Нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия сама проверяет обновления.

При первом запуске приложение скачивает yt-dlp и Deno (нужен интернет, около минуты) и проверяет их контрольные суммы.

## Возможности

- Одна или несколько ссылок сразу, плейлисты и каналы с выбором нужных видео, очередь с общим прогрессом.
- Выбор качества (вплоть до 4K, с указанием частоты кадров и размера), языка звуковой дорожки и субтитров.
- Вырезка фрагмента или главы, GIF из видео.
- Обложка и теги в MP3, M4A и FLAC.
- Подписки на каналы и плейлисты: новые видео ставятся на загрузку сами.
- История, поиск, перетаскивание готовых файлов в другие программы, сворачивание в трей.
- Действие после очереди: закрыть программу, сон или выключение компьютера.
- Если сайт требует вход или проверку «вы не бот», приложение предложит войти. Вход хранится в зашифрованном виде средствами системы.

Подробное описание всех функций, входа в аккаунты и решения проблем: [docs/GUIDE.md](docs/GUIDE.md).

## Запуск из исходников

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
npm install
npm start
npm test
```

Сборка установщика:

```bash
npm run dist:win     # Windows
npm run dist:mac     # macOS (на Mac)
npm run dist:linux   # Linux AppImage
```

## Как это устроено

Приложение написано на Electron. Загрузку выполняет [yt-dlp](https://github.com/yt-dlp/yt-dlp), конвертацию ffmpeg, JavaScript-движок для YouTube даёт Deno. Окно изолировано (sandbox, contextIsolation, строгий CSP), контрольные суммы загружаемых компонентов проверяются.

## Использование

Качайте только то, на что у вас есть права, и соблюдайте правила сайтов. Программа предназначена для личного использования: сохранения собственных материалов, работ с открытыми лицензиями, записей для офлайн-просмотра там, где это разрешено. Она не обходит платную защиту и не предназначена для скачивания платного или пиратского контента.
